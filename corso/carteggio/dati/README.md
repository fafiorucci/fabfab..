# Dati della costa per le carte schematiche

- `coast_rings.json`: linea di costa della carta 5/D (OpenStreetMap), usata da `cart/chart.py`.
- `coast42_rings.json`: linea di costa della carta 42/D, usata dalle lezioni 12, 14 e 15.

Le cartelle `cart/` delle lezioni 08, 10-15 e dell'appendice A li richiamano con link simbolici.
