# Appendice C · I nodi marinari

Mazzo di studio (20 slide): le parole dei nodi, quale nodo per quale lavoro, dieci nodi e volte in quattro passaggi disegnati
(Savoia, gassa d'amante, parlato, bozza, volta di bitta e doppino, galloccia, volta tonda e due mezzi colli, piano, bandiera, margherita),
le cime e due verifiche con i quiz ufficiali.

- `corde.py`: motore di disegno delle cime (curve 3D proiettate, sopra/sotto corretti agli incroci).
- `nodi.py`: i disegni di ogni nodo, passo per passo. `python3 kt.py gassa` crea un'anteprima PNG dei quattro pannelli.
- `genera.py`: genera le slide in `deck/project` (serve `rotta-giusta/site/dati/quiz.json` accanto, come per le altre lezioni).
