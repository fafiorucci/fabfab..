# Appendice K · Il soccorso in mare

Le emergenze (23 slide): chi coordina il soccorso, i primi minuti, falla, incendio ed estintori, collisione e incaglio, uomo a mare, segnali di soccorso, chiamare aiuto, abbandono, prevenzione, alcol e droghe, esercitazione con tre scenari. Tre verifiche con quiz ufficiali (1.3.2, 1.3.5-1.3.9, 1.3.3, 1.8.1).

`genera.py` (con `app_common.py`) produce il mazzo in `deck/project`.
