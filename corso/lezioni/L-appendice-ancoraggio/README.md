# Appendice L · L'ancoraggio

Tutto l'ancoraggio (22 slide): parti e tipi di ancora, fondali, scegliere il posto, calumo, manovra, controllo della tenuta, modi di stare alla fonda, grippia, vento forte, salpare, regole e segnali alla fonda, errori comuni. Tre verifiche con quiz ufficiali (1.4.3, 1.4.2, 1.8.2, 1.5.2).

`genera.py` (con `app_common.py` e `anc_draw.py`) produce il mazzo in `deck/project`.
